🎧 Chrome Extension for Salesfinity BDRs

FlowTheCall

Ride the call. Close the deal.
Sales-call co-pilot that auto-detects your live caller, ranks news, surfaces senior contacts, and books callbacks straight to Google Calendar.

What it does

  • Auto-detects the live caller the moment a Salesfinity call connects — name, company, country.
  • Ranks senior people at the prospect's company so you reach the decision-maker.
  • Filters Google News down to ONLY items relevant to your pitch (competitor mentions, security funding, breaches, CISO hires) with a one-line angle.
  • Built-in objection handler with copy-ready responses pulled from your own scored calls.
  • Schedule tab — multi-country World Clock, Google Calendar feed, "Call back later" and "Set meeting" buttons that pre-fill GCal with the prospect's email.
  • Optional Live Coach with real-time transcript + AI suggestions during the call.

Privacy first

Everything is stored locally on your machine using chrome.storage.local. There is no FlowTheCall backend. No analytics. No data leaves your computer unless YOU plug in your own API keys for Anthropic / OpenAI / Google Calendar features.

Audio is captured only when you click "Start" on Live Coach. It stops the moment you click Pause.

🐛 Common issues

  • The extension doesn't detect my caller — refresh the Salesfinity tab and click the Re-detect button.
  • News tab shows nothing — that's correct: it only shows Ox-relevant news. Add your Anthropic API key in Settings (⚙️).
  • Live Coach doesn't start — Live Coach requires your OpenAI and Anthropic API keys in Settings.
  • Google Calendar callback opens with wrong time — check your timezone in Chrome and your Google Calendar settings.

Requirements

  • A Salesfinity account (the dialer where calls happen)
  • (Optional) Anthropic Claude API key for news ranking, objections, Live Coach
  • (Optional) OpenAI API key for Whisper-powered live transcription
  • (Optional) Google Calendar private iCal URL for the Schedule tab
